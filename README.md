# Site JJ Divisórias

Landing page desenvolvida para a JJ Divisórias, empresa especializada em forro de PVC, forro de gesso e drywall em Brasília.

🔗 Site no ar: https://jjdivisorias.com/

## 💡 Sobre o projeto

Além do desenvolvimento da página, fui responsável por todo o processo de publicação do site, incluindo:

- 🗺️ Integração com **Google Maps** para localização do negócio
- ☁️ Hospedagem via **Firebase**
- 🌐 Configuração de **domínio próprio** para o cliente
- 📱 Integração com **redes sociais**

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Firebase (Hosting)
- Google Maps API
